# Gym Management System

A web-based application developed using Python Flask to manage gym operations efficiently.

## 🚀 Features
- Trainer Management
- Trainee Management
- Attendance Tracking
- Payment Management
- Reports Dashboard

## 🛠️ Technologies Used
- Python (Flask)
- HTML, CSS
- SQLite

## ⚠️ Limitations
- Basic authentication
- No online payment integration

## 🔮 Future Improvements
- Online payments
- Notifications
- Mobile version
